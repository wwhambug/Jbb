# JBB

같은 시드, 같은 출전표, 같은 변형이면 같은 전투가 나오는 결정론적 공 배틀 웹 게임입니다.

## 들어있는 것

- 코드로 직접 찍은 얼굴 포인트와 회전 아이템을 가진 픽셀 파이터 50종
- 파이터마다 평타 2개, 궁극기 2개, 특별기 1개
- 게이지가 100이 되면 시드 RNG가 궁극기 2개 중 하나를 선택
- 기본형, 3초 충전 후 초강력 넉백을 발사하는 슈퍼차지드, 화염형, 빙결형, 거대형, 신속형
- 표적 추적 없이 시드 기반 2축 관성으로 이동하고 벽에서 반사
- 공끼리 새로 충돌할 때 양쪽에 정확히 1 피해, 방향 반전과 누적 속도 상승
- 아이템이 실제로 회전하며 접촉 판정, 명중할수록 피해·회전·사거리 성장
- 히트스톱, 픽셀 파편, 피해 숫자, 궁극기 배너와 캐릭터별 궁극 자세
- 빈 출전표에서 직접 고르는 편성 화면과 시드 잠금 결과 지문
- 키보드와 모바일에 대응하는 반응형 UI

## 실행

```bash
npm install
npm run dev
```

프로덕션 검증:

```bash
npm run lint
npm test
```

## 결정론 규칙

전투는 고정 60Hz 스텝으로 계산합니다. 초기 배치, 궁극기 선택, 순간이동 방향 등 모든 무작위 선택은 문자열 시드를 해시한 뒤 xorshift32 난수 발생기만 사용합니다. 렌더 프레임 속도는 전투 순서에 영향을 주지 않습니다.
